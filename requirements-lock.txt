# UTILISATION (venv ISOLE, sans --system-site-packages)
#   py -3.10 -m venv .venv

# ATTENTION: install.bat / install.sh creent le venv avec --system-site-packages

# les autres apps de la machine. Pour un environnement reproductible, creer le
# venv a la main comme ci-dessus plutot que via install.bat.
#
# NE PAS regenerer ce fichier depuis un `pip freeze` d'un venv
# --system-site-packages: on y capturerait tout le site-packages global, un
